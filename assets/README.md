# Station assets

This folder holds the station's brand files:

- `logo.jpeg` — the station logo (used as the README header image and the
  ident page poster).
- `jingle.mp4` — the short station ident video (played from the ident page).

These two binary files are uploaded separately (GitHub web upload or git)
because the text-only tooling used for the rest of this repo can't push
binary files.
