# Episode transcript template

Copy this file for each session. Fill in the header, then log each track and
each exchange under it. Keep the now-playing line above every music comment —
it's what makes a transcript re-playable later.

## Header

- **Station:**
- **Episode date:**
- **Theme / starting point:**
- **Hosts on air:**
- **Playback device:**
- **Playlist (if made):** [Spotify link]

## Log

> ♪ *Now playing:* [Track Title](https://open.spotify.com/track/<id>) · Artist · *Album* (Year)
> **Ray:** ...
> **Helen:** ...
> **Listener:** ...

(Repeat the now-playing line whenever the track changes. Keep speaker labels on
every line, including the listener's.)
